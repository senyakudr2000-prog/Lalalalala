# Afterlight

**Minecraft 1.21.1 · NeoForge · Java 21**

The world is quiet. That does not mean it is empty.

Afterlight adds rare, harmless anomalies to survival:
- strange cave-like sounds from behind you;
- brief swirls of portal particles where nothing should be;
- ash-like traces and occasional unsettling whispers.

The events are deliberately subtle, infrequent, and cosmetic. They do not damage the player, change blocks, or interfere with normal gameplay. They are disabled in Creative and Spectator modes.

## Build

Use JDK 21 and Gradle 8.10 or newer:

```bash
gradle build
```

The mod jar is produced in `build/libs/`.
